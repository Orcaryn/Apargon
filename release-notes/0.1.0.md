### New

- First release. resworb opens an HTML page from disk and gives it files instead of the network.
- A page asks for folders, servers and programs in `<meta>` tags, and opens only once you approve them. A page with no tags can only look at its own folder, and opens without asking.
- The OS blocks the network for the page and every program it starts.
- At most once a day, when a page opens, resworb checks GitHub for a new version. macOS installs it the next time resworb starts; Linux shows a notice with a link. Permissions → Check for Updates Automatically turns it off.
- macOS: a signed and notarized `.dmg` for Apple silicon and one for Intel.
- Linux: a `.deb` for x86-64. Tested on a headless Ubuntu 24.04 server, not yet on a desktop.
- Windows is not supported.

[SECURITY.md](https://github.com/Orcaryn/resworb/blob/main/SECURITY.md) lists what resworb does not enforce.
