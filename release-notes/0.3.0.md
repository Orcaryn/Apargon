### Security

- macOS: 0.2.0 cut the page's process off from the Apple Events service, which also stopped the events macOS sends to it: Dock → Quit, logout, and a page opened while another was open. Now only sending is blocked, so a page's programs still cannot script other apps with `osascript` or Apple Events, and Apargon answers macOS again.

### New

- Install from the terminal: `curl -fsSL https://apargon.com/install.sh | sh`. On macOS it checks the app's signature and notarization before it replaces the installed one; on Ubuntu 24.04 it checks the `.deb` against the release's `SHA256SUMS` and installs it with apt. It also installs the papp skill for coding agents; `sh -s -- --no-skill` leaves that out.
- macOS: Homebrew. `brew trust --cask orcaryn/tap/apargon`, then `brew install --cask orcaryn/tap/apargon`. The cask follows each release.
- The popup groups what a page asks for under Programs, Files, Network and This computer, shows the page's folder and where it came from under its name, and scrolls when the list is taller than the screen.

### Changed

- The window title no longer lists the servers a page may reach. The popup still does, and the approval does not change.
