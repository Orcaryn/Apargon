### Security

- Apargon now reads a page's tags the way a browser reads `<meta>` tags. A tag counts only if `papp-` is in its `name`. Write `name="…"` and `content="…"` with quotes and no spaces around the `=`.
- `papp-run` refuses two programs with the same name. A full path must be plain (no `.`, `..` or `//`) and point to a file.
- `papp-net` refuses a port that starts with 0.
- A page could type commands into the terminal that started Apargon. Now it gets no input from it, and its output shows as plain text.
- `papp.saveAs` refuses folders where files run on their own: hidden folders, `~/Library` on macOS and `AppData` on Windows.
- A page's file API no longer shows or changes Apargon's own data.
- `papp-net` refuses `localhost:*` and `127.0.0.1:*` on every OS. Any port there includes other pages' connections.
- Red in the popup now means one thing: the page can send data to places its tags don't name. Full Node and "any server" are red. Secrets, screen recording and hidden folders are yellow.
- Running programs is now yellow. On Linux and Windows it is red if the page can also write files, because its programs can then change any file in those folders. A page that runs programs still needs you to tick "I trust this page".
- Windows: programs and `papp-node` pages can send any file they see to the internet, through Windows itself. Apargon cannot stop this. You must tick "I trust this page" before such a page opens.
- The popup's warning names the programs a page runs and the sockets it talks to.

### New

- Apargon now runs on Windows. There is an installer for x64 and arm64, but only arm64 is tested.
- The Windows installer is not signed, so Windows shows a warning. Check the file against `SHA256SUMS` in the release before you run it.
- On Windows, pages can use `papp-run`, `papp-env` and `papp-node`. Programs must be `.exe` or `.com` files. Pages with `papp-socket`, or `papp-net` to `localhost`, do not open.
- On Windows, stopping a program does not stop the programs it started. They keep running until they finish.
- Pages can open links. `papp.open`, `target="_blank"` links and `window.open` open http(s) links in your browser. Apargon shows the address and asks first, unless the page lists the site in `papp-open` or you ticked "Always".
- Pages can open files (images, video, audio, PDF, text) and folders in their usual app, if the page may see them.
- A page keeps its storage (`localStorage`, IndexedDB) when you move or rename it, if the file hasn't changed since it was last open. So after you edit a page, open it once before you move it. A copy starts with empty storage.

### Changed

- `papp-net` with `localhost:*` or `127.0.0.1:*` no longer opens. Name the port, as in `localhost:11434`.
- macOS: a page's programs can't open a terminal. Tools that need one may fail.
- Download file names no longer include the version, for example `Apargon-arm64.dmg` and `apargon_amd64.deb`. If a script downloads them by name, update it. `install.sh` and Homebrew already use the new names.
