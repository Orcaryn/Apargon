### Security

- Apargon reads a page's tags as the browser reads its `<meta>` tags. A `papp-` name counts only in a `name` attribute, never inside another attribute's value, and both `name` and `content` must be quoted with no spaces around the `=`.
- `papp-run`: two tags may not name programs with the same name, and an absolute path must be written plainly (no `.`, `..` or `//`) and lead to a file. `papp-net`: a port may not start with 0.
- The popup's red now means one thing: a way to send data somewhere the tags do not name, such as running programs or full Node. Secrets, screen capture and hidden folders are yellow.

### New

- A page can open links and files. `papp.open`, a `target="_blank"` link and `window.open` open an http(s) link in your browser. Apargon asks first and shows the address, unless the page names the site with `papp-open` or you ticked "Always". A file (image, video, audio, PDF, text) or a folder opens in its app, if the page may see it.
- A page's storage (`localStorage`, IndexedDB) follows it when you move or rename the file, as long as its content is the same as when it was last open. After you edit a page, open it once before you move it. A copy starts empty.
