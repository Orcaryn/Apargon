### Security

- `papp-net` with a wildcard host like `*:*` or `*:443` no longer reaches this computer. Only a tag that names `localhost` or `127.0.0.1` with its port does, as before.
- A program a page runs on macOS and Linux no longer inherits Apargon's pipes to the trampoline, so it can no longer send the trampoline requests as the page.
- Revoking another page's approval, or turning off the update check, now needs you to confirm first, so a `papp-system` page cannot do it on its own.
- Windows: `papp-run` shows red, as a program can send what it sees out through Windows.
- Linux and Windows: a page that runs programs may no longer write a folder that holds the page, such as its own folder through `./out*`. A program could rewrite the page. Write to a folder of its own, like `./out/*`.
- Saved files get the download mark on macOS and Windows, so the OS warns before one runs.
- More logins are hidden: Claude Code, Codex, 1Password, crates.io, RubyGems, Terraform, Vault, Hugging Face, keychains, `_netrc`.
- `papp-net` refuses short numeric hosts like `127.1`.
- A `papp-system` page changes only the files its `papp-write` tags name. On macOS it can no longer open apps or send Apple Events.
- Keys and logins are no longer hidden from the sandbox. The popup names them instead: a tag that reaches `~/.ssh` says "See your SSH keys", in yellow. A `papp-system` page, and the programs a page runs, read them like any file.
- A page quits if Apargon's own process dies.
- Windows: the offline check also tries an address off this computer. Blocking only this computer no longer passes.
- `~` in a path can no longer lead elsewhere when the home folder's name has a `$`.
- minimatch updated to 11.0.1 (GHSA-g3hv-75wg-m249).

### Not enforced

- A page with `papp-net` can send what you pick for it, and the secrets it keeps.
- On Linux without a keyring, a page's secrets are only obscured on disk.
- With `papp-listen network`, every device on the network gets what the page answers.

- With no tag, a page can add menus with any label and see sleep, lock, battery and idle time.
- `papp.save` suggests the name and folder, so you only have to press Save and Replace.
- `papp-use print` reaches every printer the computer knows, network ones too.
- `papp-use midi` also allows system-exclusive messages, which can change an instrument's settings or update its firmware.
- Windows: `papp.save` follows a link at the picked name.
- Windows: a page can reach the print spooler without `papp-use print`, by working around `papp.print`.

### New

- `**` in `papp-read` and `papp-write` matches any number of folders: `~/notes/**/*.md` is every `.md` file under `~/notes`. One `*` per name and one `**` per path.
- `papp.pick` keeps what you pick, until you take the page's approval back. Apargon's own dialog says what the page gets, and with `write: true` the page can change it too. The popup lists the picks under "You gave it". `papp.given()` lists them for the page.
- `papp.getSecret`, `papp.setSecret` and `papp.deleteSecret`: a page keeps keys sealed with your computer's own store, where no page can read them.
- `papp.connect`: a TCP connection, with or without TLS, to a host and port `papp-net` names. For database, mail or chat clients.
- `papp-listen localhost` or `network`: Apargon answers requests for the page, from programs on this computer or devices on your network. The page never listens. Both are red.
- `papp-run ./bin/tool`: a program the page ships, run by its name. Refused if the page could change it.

- `papp-window`: size (`size=900x600`, or `width` and `height`), minimum size, resizable, title bar, frame, see-through, on top. No frame, see-through and on top show yellow.
- Windows reopen where you left them.
- `papp-use print`: `papp.print()` and `window.print()`. Any page can make a PDF with `papp.pdf()`.
- `papp.save`: save one file where you pick. It can replace a file; the OS asks first.
- `papp-use usb`, `serial`, `hid`: one device you pick. `papp-use midi`: MIDI instruments. On macOS, serial ports include Bluetooth ones, so macOS asks for Bluetooth.
- `papp-use background`: keeps running after you close the window. Quit from the tray icon.
- `papp-use login`: opens at login, until you take back the approval.
- Notifications show the page's icon and up to three buttons.
- `papp.menu` and `papp.contextMenu`: a page's own menus.
- `papp.tray` takes items of the page's own, above Show and Quit. `papp.onTray` says which one you clicked.
- `papp.progress`: a progress bar on the dock or taskbar icon.
- `papp.onSystem` and `papp.power`: sleep, wake, lock, battery and idle time.
- `papp-global-shortcut` takes media keys alone, like `MediaPlayPause`.
- Screen sharing: pick a screen or a window.
- Linux and Windows: each page has its own taskbar icon and title. A pin reopens it.
- Windows: camera, microphone and location work. Not yet tested on real devices.
- Windows: `papp-net` to `localhost` works, through Apargon's proxy.

### Changed

These need a page edit:

- `papp.saveAs` is now `papp.saveAll`, as it saves several files into a folder. `papp.save` still saves one.
- `papp.readFile` takes its options in one object: `readFile(path, { encoding: null })` for bytes, `{ offset, length }` for part of a file. `readFile(path, 'utf8')` is refused.
- `papp.rm` removes a folder only with `rm(path, { recursive: true })`, as in Node.
- `papp.watch` gives a handle, as `papp.listen`, `papp.connect` and `papp.spawn` do: `close()` stops it, and `closed` resolves once it has stopped. `closed` says why when a watch stops on its own.
- `papp.spawn`: `kill()` is now `close()`, and `done` is now `closed`.

- A pick no longer ends when the page reloads.
- Picks, links ticked "Always" and secrets all go when an approval is taken back.

- `papp-node` is now `papp-system`. A page with `papp-node` no longer opens: rename the tag.
- `papp-shortcut` is now `papp-global-shortcut`. A page with `papp-shortcut` no longer opens: rename the tag.
- `papp-net` uses port 443 when you leave the port out: `api.example.com` is `api.example.com:443`. A host on this computer or the local network still needs its port. `papp-net` `*` no longer opens: write `*:443` or `*:*`.
- `papp-use` takes a list: `content="camera, microphone"`.
- The popup is easier to read. Each heading says what the page can do, like "Can see" or "Can run", and each row shows only the file, program or site. A file in the page's folder shows as `./name`. A file or folder icon shows which is which. The red box above the list shows only when a line is red.
- The tray icon opens a menu (Show, Quit). A click no longer brings the window forward.
- `window.close()` closes like the close button. With `papp-use background`, it hides the window.
- Programs reach a declared `localhost` port through Apargon's proxy on every OS, and it is logged. Programs must honour `http_proxy`.
- A host declared with a trailing dot, like `example.com.`, names the same host.
- `papp-system` takes `papp-write` and `papp-read`.

### Fixed

- A page opens again on a Mac with a hidden folder such as `~/.ssh`: its process looked up the folder's real path, which its own sandbox refuses.

- `papp.copyFile` no longer loads the whole file into memory.
- A failed `papp.watch` closes.
- A bad request from a page is logged, not shown as an error box.
- A `papp-system` page's output line that starts with `{` is shown as output, not taken for a broken request.
- Apargon forgets a page once its file and storage are gone.
