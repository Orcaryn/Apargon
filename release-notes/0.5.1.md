### Security

- The popup groups its lines under headings: "Change files in", "Use", "Send your files to", "Control", "Share with its programs" and "Also".
- The full place a line names, such as a folder's path, now shows when you hover over the line or focus it, not under it. Two `papp-write` folders with one name show their places in full.
- **What This File Can Do…** groups its lines the same way.
- Every `.papp` file with a tag asks again once, as the popup's lines changed. The popup says the file changed since you said yes. It didn't.
- `SECURITY.md` now names these gaps. 0.5.0 had them too:
  - Linux: a `papp-write` folder on a network drive is not hidden, and what's written there leaves the computer.
  - Linux in a virtual machine: `papp-socket` reaches the machine's host.
  - macOS: a `.papp` file with `papp-write all`, or `papp-write` on `~/Library/Logs`, can change the egress log.
  - macOS: a file that `papp.*` writes over is not marked as downloaded, and neither is what programs write under `papp-write all`.
  - Windows: a `.papp` file writes to your temp folder, which other apps share.
- `SECURITY.md` now says macOS 13 or newer. It said 12.

### Changed

- A `.papp` file with `papp-read` or `papp-open` is still refused, now as an unknown tag. The message no longer says what to write instead.
