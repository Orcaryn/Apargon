### Security

- A pick to write now lasts until the `.papp` file closes. Before, a file or folder you picked or saved to stayed writable for good, even after a restart. To keep a folder writable, name it in `papp-write`.

### New

- When a papp crashes or runs out of memory, Apargon asks whether to reload it or quit. Before, its windows stayed blank.

### Changed

- `papp.picks()` is gone. Call `papp.pick` again when the app opens, or name the folder in `papp-write`.
- Apargon keeps its data in `~/.apargon/.data` on every OS. Nothing moves over from before: each `.papp` file with tags asks again, saved secrets aren't read, windows open at their default place, and the automatic update check is on again.
- You can delete the old data folder: `~/Library/Application Support/Apargon` on macOS, `~/.config/Apargon` on Linux, `%APPDATA%\Apargon` on Windows.
- The papp skill's first example works as written, and its `papp-write` examples use a path from the `.papp` file's folder or `~/`.

### Fixed

- Live reload no longer reloads when only a file's attributes change, such as its Finder icon or tags.
- A PDF shows inside a frame.
- A papp that fails to start shows the error and quits. Before, it stayed open with no window.
- macOS: a papp's Dock icon uses less memory.
- Finder and Windows call a `.papp` file a "papp file", not a "papp page".
