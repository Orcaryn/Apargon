### Security

- The yes now also covers each `.js` and `.css` file, and each other `.papp` file, that a `.papp` file loads. A change to one asks again. Before, only the `.papp` file's own bytes counted.
- Not covered: code loaded under any other ending, and a file the `.papp` file may write itself.
- A `.papp` file can now do these without a tag: keep the screen awake, read each screen's size and place, see when the user is idle, list installed fonts, lock the keyboard, ask to keep its storage, and pick a speaker. None of them reaches off the computer.

### New

- The web's `Notification` works with `papp-use notifications`.
- A download, such as `<a download>`, saves through Apargon's save dialog.
- When a script or style changed since the yes, the popup names the file.

### Changed

- `papp.displays()` is gone. Use `window.getScreenDetails()`.
- `papp.notify` answers `'click'` when the user clicks the notification itself. Before, it answered `null`.

### Fixed

- `papp.notify` gives an error when the system refuses the notification. Before, it never answered.
